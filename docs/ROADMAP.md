# MobMind Roadmap

## Phase 1: Zombie Awakening
- Awareness growth.
- Level-1 zombie leader.
- Small team roles.
- Group combat and retreat.
- Daylight avoidance.
- Simple shelter work.
- Shared inventory.

Status: in progress, playable prototype.

## Phase 2: Better Feedback
- Awakening particles.
- Leader roar/sound cue using vanilla sounds.
- BossBar for active leader groups.
- Better debug commands.
- Optional player chat warnings when a leader awakens nearby.

## Phase 3: True Nest System
- Persistent nest position per group.
- Nest claim radius.
- Decoration blocks:
  - cobweb
  - mossy cobblestone
  - bone block
  - soul sand
- Configurable block palette.
- Nest growth limits.

## Phase 4: Leader Progression
- Level 2 and higher leaders.
- Larger control capacity.
- More specialized roles.
- Better equipment priority.
- Resource-based upgrades from shared inventory.

## Phase 5: More Mob Types
- Skeleton leaders.
- Spider packs.
- Creeper ambush groups.
- Cross-species alliances only after single-species behavior is stable.

## Phase 6: Player Counterplay
- Destroying nests weakens groups.
- Killing patrols delays attacks.
- Stealing shared inventory resources.
- Light and defensive builds matter more.
